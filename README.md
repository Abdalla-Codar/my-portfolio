# abdalla walid — Personal Portfolio

A responsive, single-page personal portfolio built with HTML5, custom CSS, Bootstrap 5, and a small JavaScript enhancement.

## Project structure

```text
abdalla-walid-portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
│   └── profile-placeholder.svg
└── README.md
```

## Run locally

1. Download or extract this folder.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for Bootstrap CDN and Google Fonts. The page layout and custom styling are in the local project files.

For a more convenient local development workflow, open the folder in VS Code and use the Live Server extension.

## Publish with GitHub

### Option A — GitHub website

1. Sign in at https://github.com/.
2. Click **New repository**.
3. Name it `abdalla-walid-portfolio`.
4. Choose **Public** if your instructor needs to access it without signing in. Do not upload passwords or private information.
5. Create the repository.
6. Click **Add file → Upload files**.
7. Upload `index.html`, `css/`, `js/`, `assets/`, and `README.md` while preserving the folder structure.
8. Commit the changes.

### Option B — Git from a terminal

Run these commands from inside the project folder after creating an empty GitHub repository:

```bash
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/abdalla-walid-portfolio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your actual GitHub username. If Git asks you to sign in, complete GitHub's authentication flow.

## Publish the live website with GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for deployment. Your live site URL will usually be:
   `https://YOUR-USERNAME.github.io/abdalla walid-portfolio/`

The repository link and the live website link are different. Submit the repository link if the assignment specifically asks for the GitHub repository; you can also include the live website link if the form allows it.
